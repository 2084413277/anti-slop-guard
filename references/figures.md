# Figure ideation and execution

## Choose the active mode from the author instruction

### Precise edit mode

Use this mode when the author names a bounded visual change. Apply the specified edit. Preserve the remaining layout, evidence structure, data, annotations, and style.

### Ideation mode

Use this mode when the author requests inspiration, redesign, visual alternatives, or exemplary figures.

Before drawing:

1. identify the scientific role stated by the author;
2. retrieve three to five relevant high-quality exemplars;
3. explain one transferable design principle from each exemplar;
4. distinguish unsuitable elements from useful elements;
5. offer two or three materially different visual directions;
6. let the author select the implementation path.

Useful directions include:

- a restrained evolution of the current composition;
- a hierarchy-led reorganization with one primary panel;
- an alternative chart form or evidence sequence.

## Avoid accumulation

Every panel, legend, color, annotation, and decorative element needs a distinct information role. Preserve space and hierarchy. Remove repeated evidence when the author authorizes redesign.

Do not extend a weak structure solely because it already exists. Do not treat an exemplary figure as a complete template. Transfer design logic and preserve the author's scientific logic.

Reference retrieval supports author thinking. The author selects the direction. Implementation begins after that selection.
